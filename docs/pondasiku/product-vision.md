# Product Vision - PondasiKu

## Vision Statement

> **"Menjadi platform digital terpercaya untuk kebutuhan material bangunan, menghubungkan toko material dengan kontraktor, tukang, dan pemilik rumah dalam satu ekosistem yang mudah dan efisien."**

---

## Target Persona

### Persona 1: Pemilik Rumah (Pelanggan Individu)

| Aspek | Detail |
|-------|--------|
| **Nama** | Pak Andi |
| **Usia** | 30-50 tahun |
| **Pekerjaan** | Karyawan swasta / wiraswasta |
| **Lokasi** | Perumahan, area pembangunan |
| **Tujuan** | Membangun/renovasi rumah dengan material berkualitas dan harga terjangkau |
| **Frustrasi** | Tidak tahu material apa yang dibutuhkan, bingung hitung kebutuhan, harus keliling toko |
| **Kebutuhan** | Konsultasi material, kalkulator kebutuhan, delivery ke lokasi |
| **Behavior** | Cari info online, bandingkan harga, minta rekomendasi tukang |

---

### Persona 2: Kontraktor/Tukang (Pelanggan Profesional)

| Aspek | Detail |
|-------|--------|
| **Nama** | Bang Joko |
| **Usia** | 30-55 tahun |
| **Pekerjaan** | Kontraktor / Tukang bangunan |
| **Lokasi** | Area proyek |
| **Tujuan** | Mendapatkan material dengan harga grosir, pengiriman tepat waktu |
| **Frustrasi** | Stok tidak tersedia saat butuh, koordinasi pengiriman rumit, pembayaran bertahap |
| **Kebutuhan** | Harga khusus kontraktor, order bulk, jadwal pengiriman fleksibel |
| **Behavior** | Order via WhatsApp, hubungi langsung, repeat order |

### Persona 3: Pemilik Toko Material (Admin Utama)

| Aspek | Detail |

### Persona 4: Karyawan Toko (Operator)

| Aspek | Detail |
|-------|--------|
| **Nama** | Dimas |

## Value Proposition

### Untuk Pelanggan (Pemilik Rumah & Kontraktor)

| Value | Benefit |
|-------|---------|
| **Kemudahan** | Belanja material dari mana saja, tidak perlu keliling toko |
| **Transparansi** | Harga jelas, stok real-time, tidak ada biaya tersembunyi |
| **Kalkulator** | Hitung kebutuhan material otomatis (semen, bata, cat, dll) |
| **Delivery** | Pengiriman ke lokasi proyek dengan armada toko |
| **Konsultasi** | Rekomendasi material sesuai kebutuhan proyek |

### Untuk Pemilik Toko

| Value | Benefit |
|-------|---------|
| **Efisiensi** | Otomatisasi stok, pesanan, laporan |
| **Jangkauan** | Pelanggan tidak terbatas yang datang ke toko |
| **Insight** | Data penjualan untuk keputusan bisnis |
| **Piutang** | Sistem kelola piutang kontraktor/developer |
| **Scalable** | Siap untuk ekspansi |

---

## Unique Selling Points (USP)

1. **Material Calculator** - Kalkulator kebutuhan material otomatis (luas → jumlah material)
2. **Professional Pricing** - Harga khusus untuk kontraktor/developer
3. **Bulk Order** - Sistem pemesanan dalam jumlah besar dengan jadwal pengiriman
4. **Local Trust** - Toko material lokal yang sudah dikenal, bisa cek fisik
5. **Flexible Payment** - Pembayaran bertahap untuk pelanggan terpercaya
